# 知芽功能型移动网页原型

直接打开 `index.html` 即可运行，不需要安装依赖或启动服务器。

## 已接入的项目数据

- `data/seed/story_pages.json`：20 本绘本的 104 个页面文字
- `knowledge-base_v2.0/绘本样例集_v2.0.md`：书名、年龄段、主题、画面描述和互动问题
- `knowledge-base_v2.0/图片/`：19 张真实封面，缺少 `PIC-B20` 时使用文字封面

## 已实现功能

- 20 本绘本独立详情和真实页面内容
- 中文书名、主题和拼音搜索
- 逐字拼音显示
- 浏览器中文语音朗读、暂停和停止
- 阅读中按字高亮
- 翻页与完成阅读
- 阅读记录保存到浏览器本机
- AI 共读提示示范
- 孩子档案和年龄段设置

## 资源限制

当前仓库每本绘本只有一张封面插画，没有逐页插画和正式配音文件。原型会在不同页切换封面焦点并显示该页画面描述，朗读使用浏览器语音合成。真正的逐页插画与统一配音需要后续补齐素材。
