# 知芽后台管理原型

直接双击 `index.html`，使用 Edge 或 Chrome 打开，无需安装依赖。

## 页面

- 工作台
- 绘本管理
- 版本审核
- 领域知识库
- 接口与权限

## 交互

- 左侧导航切换页面
- 绘本搜索、状态筛选和年龄筛选
- 知识条目搜索、审核状态与类别筛选
- 点击绘本打开详情抽屉
- 审核通过后更新发布状态
- 新增绘本、新增知识和版本审核弹窗
- 发布与审核状态保存在浏览器本地

## 数据来源

数据来自 `MumLauds/202610-zhiya` 仓库的 `data/seed/story_versions.json`、`story_pages.json`、`knowledge_items.json`，共 21 个绘本版本、19 张真实封面和 20 条领域知识。
